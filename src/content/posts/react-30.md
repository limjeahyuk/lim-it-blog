### **\- Class**

클래스는 객체를 위한 **프로퍼티**와 **매소드**를 가질 수 있습니다.

**프로퍼티**란 클래스에 정의한 **변수**

**메소드**란 클래스에 정의한 **함수**

클래스를 생성할 때는 new를 사용하며 상속도 가능합니다.  
다른 클래스에 있는 프로퍼티와 메소드를 상속하면 잠재적으로 새로운 프로퍼티와 메소드를 추가합니다.

예시로 알아보면

![](/images/react-30/1.png)

constructor() 은 기본 생성자로 class가 생성되면 바로 실행되는 구간입니다.  
그 안에서 name 이라는 변수를 지정해줬기 때문에 **프로퍼티**가 됩니다.

printMyName() 이라는 함수를 정의 해줬기에 **메소드**가 됩니다.

클래스를 생성할 때는 new를 이용하여 만들어 줬습니다.  
그렇게 결과가 알맞게 나옵니다.

여기에 새로운 클래스를 만들어 상속을 해보면

![](/images/react-30/2.png)

extends를 이용하여 Human 클래스를 상속받고 있습니다.

Human 클래스도 동일하게 constructor() 기본 생성자를 이용하여 gender이라는 변수를 지정하고 있으니 프로퍼티,

printGender() > 메소드 를 추가했습니다.

상속할 때는 서브 클래스에서 super 생성자를 먼저 호출해줘야 합니다.  
상위 클래스의 생성자 함수를 실행하는 데 쓰는 키워드로  
super를 통해 올바른 상위 클래스를 초기화해야 합니다.

* * *

위 구문들은 구세대 버전으로 우리가 알고 있는 화살표 함수를 사용하면 매우 간단하게 바꿀 수 있습니다.

![](/images/react-30/3.png)

위에 구문과 똑같은 내용이지만 코드 자체는 매우 간결해졌습니다.

메소드는 화살표 함수를 사용하므로써 값으로 함수를 저장하는 프로퍼티라고 생각하면 됩니다.  
프로퍼티의 값으로 화살표 함수를 사용하기 때문에 this 키워드를 사용하지 않아도 됩니다.  
그렇기에 생성자 또한 필요 없어지게 됩니다.

화살표 함수로 인해 생성자와 this가 사라지니 코드가 보기 좋아졌습니다.

### **\- 스프레드 / 레스트 연산자**

{ ... } 으로 이루어진 연산자.

어디에서 사용하는지에 따라 **스프레드**와 **레스트**로 다르게 부릅니다.

**스프레드** 연산자는 배열의 원소나 객체의 프로퍼티를 나누는 데 사용.

**레스트** 연산자는 함수의 인수 목록을 배열로 합치는 데 사용.

먼저 스프레드부터 가보면

![](/images/react-30/4.png)

이런 식으로 ... 을 사용하여 numbers 배열에 있는 모든 원소들을 새로운 newNumbers 배열에 추가하고  
거기에 원소 4를 더 추가하였습니다.

만약 ... 을 사용하지 않는다면?

![](/images/react-30/5.png)

새 배열에 하나의 원소로 포함되었습니다.

원하는 상황에 알맞게 사용하면 될 것 같습니다.

다음은 객체를 보도록 하겠습니다.

![](/images/react-30/6.png)

새 javascript 객체 newPerson을 생성한 다음 person 객체의 모든 프로퍼티 값을 복사하기 위해서  
person에 스프레드 연산자를 사용했습니다. 그리고 새로운 프로퍼티를 추가합니다.

이런 식으로 아주 쉽게 배열을 복사하거나,  
안전하게 이전 객체를 복사하여 객체에 프로퍼티를 추가하는 작업을 하는 것이 **스프레드** 연산자입니다.

* * *

**레스트** 연산자는 사용빈도는 낮지만 함수에서 사용합니다.

![](/images/react-30/7.png)

... 레스트 연산자를 사용하여 매개변수를 배열에 통합했습니다.  
그리하여 배열에서 전달되는 모든 원소들에 대해 함수를 실행합니다.  
1, 2, 3 에서 1과 같은 값을 찾아서 배열로 만들었습니다.
