## 직접 게임을 해보고 난 생각들

> 생각보다 재미있자나!



제 게임 취향에 좀 맞아서 그럴 수도 있는데.. 이거? 좀 괜찮은데? 라는 생각이 들었습니다.

난이도와 여러개만 좀 정하다보면

~~그냥 제가 만들어서 그럴 수도 ... ㅎㅎ~~



그렇다보니까 실제로 해보고 결정해야할 것들이 꽤나 많이 생각이 났습니다.

### 보관함

우선 보관함이 정말 꽤나 쓸모있었습니다.

처음에는 없어도 되지 않을까 싶었고 약간 별로였지만 보관함 하나로 보드를 깨끗하게 유지할 수 있었으며

정말 큰 도움이 되었습니다. 조금 더 공격적(?) 으로 게임을 진행할 수 도 있었던 것 같습니다.

만약 보관함 없었으면 원하는 조각을 얻기위해서 계속 재설정을 돌렸어야할지도 모릅니다.



그렇기 때문에 보관함으로 난이도 설정도 많이 필요할 듯 합니다.

#### 보관함 개수

현재는 2개입니다.

그런데 2개까지? 제가 할 때는 하나는 노는 경우가 좀 있었던 것 같습니다.

아무래도 후반까지 많이 못가서 그럴 수도 있지만... 

<mark>2개일 필요성이 있을까?</mark> 라는 생각이 들었습니다.

#### 보관함 잠금장치

항상 열려있으면 말이 안되게 쉬워지는 것 같다는 느낌을 받았습니다.

왜냐하면 서랍에 정사각형을 만들어서 넣고 나서 남은 찌꺼기들을 보관함에 넣었다 빼면서 그것들을 예쁘게 정리를 하면

너무 쉽다는 생각이 들었습니다.

<mark>그럼 패널티가 없는거 아닌가?</mark>



제가 생각한 것은 잠금 장치 입니다.

한 번 꺼내서 쓰면 보관함이 잠기고 보드에 몇개의 도형을 놓으면 그때서야 다시 보관할 수 있도록

이러면 후반에 정말 잘 사용해야할 듯 합니다.

또한 초반에 망치는 경우도 보관함으로 어느정도 막을 수 있을 것 같습니다.

아무래도 초반에는 보드에 도형을 놓는게 많기 때문에 금방 잠금이 풀리게 됩니다.

```
초급 : 1번
중급 : 2번
고급 : 3번
```

이렇게 하되 해보고 수정이 필요할 수 있습니다.

### 모바일

처음에는 pc에서만 가능하게 하려했는데..

지하철에서 잠깐 하기 좋을 것 같아서 모바일을 생각 안 할 수 없었습니다.

그렇기 때문에 모바일 화면이 필요할 것 같아서 Claude에게 디자인을 맡겨서 어느정도 만들었습니다.

한 화면에서 스크롤 없이 하는 것을 목표로 디자인을 하고 싶은데.,..

그나마 줄일 것은 서랍장인것 같습니다.

### 튜토리얼

저는 깔끔한것이 좋습니다.

그렇기 때문에 쓸데없는 버튼은 없애고 싶습니다.  
예를 들어서 카드 뽑기 버튼 → 덱 클릭



전체적으로 이렇게 쓸데없는 버튼은 다 없애고 그냥 자연스럽게 클릭을 하게 하고 싶은데

이런 것들을 어떻게 처음에 알려줘야하지? 라는 생각이 계속 있습니다.



처음 하는 사람에게 이 룰들을 설명하는 것과 버튼들을 알려주는 것..

어떤식으로 해야하지?



그래서 제가 처음에 스파이더게임을 접했을 때는 어떻게 알았지? 하고 보니까

**<mark>힌트</mark>**라는 것을 사용하면서 알게 되었던 것 같습니다.



힌트를 사용하면 카드에 불빛이 들어오는데 이런것을 이용해서 클릭이 되는구나! 또는 아 순서대로 배치하는 거구나! 하고 알게 되었던 것 같습니다.



근데 저희 게임은 힌트를 어떻게 줘야하지?

이 부분도 고민을 해야할 것 같습니다.

### 애니메이션

이건 무조건 있어야할 것 같습니다.



- 덱에서 카드가 뽑히는 애니메이션
- 남은 카드가 다시 덱으로 들어가는 애니메이션



만약 여기서 더한다면.. 보관함 또는 서랍장에 도형이 들어가는 애니메이션 까지



이 부분은 추후에 업데이트 예정입니다.

당장 급한 건 아니니깐요.

### 회전 가능

처음에는 도형 회전이나 반전은 안되도록 할 계획이였습니다.

그런데 해보니까 난이도가 너무너무 높아서.. 이게 되나? 싶었습니다.



회전 가능하도록 하니까 이제 좀 편안 해졌습니다.

그래도 반전은 안되도록 하였습니다. 반전까지 가능해버리면 너무 쉬운건 둘째치고 다른 도형들 중 같은 도형으로 되어버리는 경우가 생겨버리기 때문입니다.

좀 많이 힘들 수도 있는데... <mark>자르는 기능</mark>을 넣어야할까?....

이 부분은 좀 고민이 필요할 듯 할 것 같습니다.

### UI UX

도형을 클릭 하거나 드래그 하면 도형이 위에 투명하게 뜨도록 할까 했습니다.  
그런데 현재는 그냥 판에 예상도만 뜨기만 합니다.

이부분은 처리하는 게 더 나을 것 같습니다.

폰에서 불편하지 않을까 싶었는데... 사용자가 어떤 색상을 들었는 지 까먹을 수도 있으니까..?

### 점수

점수 측정 방식에 대해 생각을 해봤습니다.

1. 정사각형을 만들때
   - 3x3 : +300점 , 4x4 : +400점 .... 8x8 : +800점
2. 색상의 서랍을 다 모았을 경우
   - + 700점
3. 덱 재구성시
   - - 1000점



고려 사항인 점.

- 보관함 사용 - 점수?
- 5장을 다 사용했을때 + 점수 or 덱 뽑기를 눌렀을 때 - 점수?



결국 게임 중간에 점수가 - 점수로 진입을 하는 순간 게임 over로 되도록 할 예정입니다.

그래야 초반에 막 하는 것을 방지할 수 있을 것 같습니다.



대충 이정도가 MVP를 해보고 느낀 고칠 점들인 것 같습니다.

좀 더 생각을 해서 기획서를 더 고도화 시켜야할 듯 합니다.
