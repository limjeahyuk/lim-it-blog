### **\- Destructuring ( 구조 분할 )**

배열의 원소나 객체의 프로퍼티를 추출하여 변수에 저장할 수 있게 해주는 것.

전에 공부했던 **스프레드**와 비슷하다고 느껴질 수 있겠지만

**스프레드**는 모든 원소와 프로퍼티를 가져와서 새 배열이나 객체에 전달하는 것.  
그에 반해 **destructuring**은 원소나 프로퍼리를 하나만 가져와서 변수에 저장.

예시를 알아보자면  
먼저 배열의 Destructuring

![](/images/react-31/1.png)

numbers 배열을 선언해주고 그 배열안에서 num1, num3을 가지고 왔습니다.  
1, 2 만 보이고 싶다면 \[num1,num2\] 이런 식으로 할당해주면 됩니다.

객체의 Destructuring

```html
{name} = {name: '혁', age: 24}
console.log(name) // 혁
console.log(age) //undefined
```

이런 식으로 { 중괄호 } 를 사용하여 속성 이름을 사용하여 속성을 대상으로 지정하는 구문입니다.  
age는 추출하지 않기 때문에 undefined로 나오게 됩니다.

**배열이나 객체안에 값을 쉽게 받아오는 걸 Destructuring이라고 합니다.**

### **\- 참조형과 기본형 자료 ( 매우 중요 ★ )**

const number = 1;  
const num2 = number;

위의 간단한 코드는 num2 가 number의 값을 복사해 온 것입니다,  
string number boolean 전부 기본형 자료 타입입니다.그럼 객체와 배열은??  
먼저 말하자면 객체와 배열은 참조형입니다.

예시를 들어보자면

![](/images/react-31/2.png)

이 구문의 경우  
분명 person의 값을 바꾸고 secondPerson의 결과를 보여달라고 했는데 person에서 바뀐 값이 보여졌습니다.  
우리는 person의 값을 바꾸고 secondPerson의 값은 전혀 건들지 않았는데 말이죠.

**이유는??** 

객체 person은 메모리에 저장되어있고, 상수 person에는 메모리에 있는 주소를 가리키는 포인터를 저장한 것입니다.  
secondPerson은 그 포인터를 복사한 것입니다.

저 나름대로 생각해본 결과 윈도우 바로가기 같은 느낌입니다.  
객체에 가는 길을 복사했을 뿐이지 그 자체를 새롭게 만든 것은 아닙니다.  
그렇기에 안에 내용이 바뀌면 같이 바뀌게 됩니다.

이것을 잘 이해하지 못하면 우리가 프로젝트를 하면서 원치 않는 결과를 얻을 수 있습니다.  
그렇기에 변경할 수 없는 방법으로 복사하려면 우리가 배운 스프레드 연산자를 사용해야 합니다.

![](/images/react-31/3.png)

전의 코드에서 스프레드 연산자 ( ... ) 만 추가해줬을 뿐인데 결과가 아예 달라졌습니다.

스프레드 연산자를 이용해서 주소를 복사한 것이 아닌 객체 안의 내용 자체를 복사했습니다.

정리하자면  
**재할당하면 값이 아닌 포인터를 복사하는 것이고**  
**복사하고 싶다면 새로운 객체를 생성해서 전체 객체를 복사하는 것이 아닌 프로퍼티를 복사해야 합니다.**

### **\- map 함수**

map 함수는 내장된 배열 메소드입니다.  
react를 하면 정말 많이 사용하는 배열 함수 중 하나입니다.

![](/images/react-31/4.png)

map 함수를 이용하여 numbers 안에 있는 모든 원소를 2배씩 곱해줘서 새로운 배열을 반환했습니다.

**map 메소드는 모든 값을 새로운 배열로 반환합니다.**
