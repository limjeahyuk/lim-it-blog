### **\- 이벤트 리스너**

이제까지 배운 props, component만을 사용하면 매우 정적인 컴포넌트가 만들어집니다.

고작 정적인 화면을 만들려고 리액트를 시작한 것은 아니기에

클릭했을 때 변화하는 이벤트 리스너를 추가할 것입니다.

![](/images/react-35/1.png)

이런식으로 onClick이라는 특별한 props를 추가합니다.  
그 뒤에는 클릭했을 시 어떤 일이 일어날 것인가를 선언해주면 됩니다.  
위 코드는 클릭했을 시 콘솔창에 cl 이 나오도록 했습니다.

onClick 와 같은 props를 on props라고 하는 이벤트 핸들러입니다.  
이러한 이벤트 핸들러의 경우 값으로 함수가 필요합니다.

현재 코드는 바로 옆에 화살표 함수로 만들어 줬지만  
이렇게 쓰게 된다면 코드가 매우 더러워지고 보기 힘들어집니다.  
그렇기에 위에 따로 빼주는 식으로 사용합니다.

![](/images/react-35/2.png)

이렇게 위에 const로 함수를 선언해주고 onClick props에 clickHandler를 지정해줍니다.

![](/images/react-35/3.png)

이런 식으로 콘솔창에 매우 잘 나타날 것입니다.

그런데 약간 의문이 생길 것입니다. 분명 clickHandler라는 함수를 만들어 지정해준다고 했는데...  
다른 자바나 c언어 코드는 함수를 사용할때 clickHandler()를 사용합니다.  
옆에 ( ) 가 들어가는 데 이건 변수처럼 사용합니다.

그 이유는 우리가 사용하는 리액트는 jsx코드를 사용하기 때문입니다.  
jsx 코드를 웹에 보여질 때 코드 라인들을 쭉 분석합니다.  
분석하다가 함수가 있다면 자바스크립트에서 실행을 해버립니다.  
그렇게 되면 클릭했을 때가 아닌 처음 렌더링 되었을 때 실행을 해버립니다.

![](/images/react-35/4.png)

이런 식으로 시작을 하자마자 4번이 찍힙니다.

우리가 원하는 것은 버튼을 클릭했을 때! 만 함수가 실행되는 것을 원하기 때문에  
함수 이름을 지정만 해주고 클릭했을 때 그 함수가 실행되도록 만듭니다.

* * *

### **\- jsx의 작동 방식**

갑자기 왠 작동 방식인가 싶을 것입니다.

우리가 화면에 나오는 글씨를 바꾸고 싶을 때 사용하는 방법 중 하나는 변수값을 지정해주고  
버튼을 눌렀을 때 변수를 변경해주는 방법이 있습니다.

```html
let title = props. title;

  const clickHandler = () => {
    title = 'up';
  };
```

이렇게 하게 되면 분명 clickHandler는 돌아가지만 화면은 변하지 않습니다...  
title은 up으로 변경되었고 그럼 up로 바뀌어야 할 텐데....

그 이유는  
리액트가 jsx를 어떻게 실행하고 화면을 작동시키는 지 알아야 state를 어느 정도 이해가 가능할 것 입니다.

**컴포넌트는 함수형입니다. 특별한 점이라면 JSX를 반환 한다는 것입니다.**

![](/images/react-35/5.png)

이런 식으로 컴포넌트를 함수 불러오는 것처럼 사용했습니다.

JSX 코드 안에 있는 컴포넌트를 이용하여 리액트가 우리 컴포넌트 함수를 인식합니다.  
코드를 평가할 때 마다 함수를 호출하고 평가한 JSX 코드를 반환합니다.  
계속해서 함수들을 호출하면서 JSX 코드를 통과합니다.

끝에서는 더이상 호출 할 함수가 없을 때 까지 통과합니다.

그렇게 나온 결과를 화면에 그려줍니다.

하지만 문제가 생깁니다.  
리액트는 이후 이 짓을 반복하지 않습니다.  
리액트는 응용프로그램이 처음 렌더링 되었을 때 그 모든 과정을 실행하고  
그 이후에는 끝입니다.

그렇기에 위에서 말한 것처럼 변수로 초기값을 설정하고.. 업데이트 하고... 무슨 짓을 해도  
렌더링을 하지 않기에 화면은 변하지 않습니다.

**그럼 어떻게 화면을 업데이트 하나요?**

우리가 리액트에게 어떤 컴포넌트가 변경되어서 재평가 되었어! 라고 말해줘야합니다.  
그 때 사용하는 것이 state라는 개념입니다.

* * *

### **\- State**

위에서 말한 것처럼 리액트는 일반적인 변수들의 업데이트로는 바뀌지 않습니다.  
그렇기에 컴포넌트의 값이 바뀌었으니 화면 좀 다시 바꿔줄래? 라고 전달해줘야합니다.

State를 사용할 때는 

```html
import React, { useState } from 'react';
```

를 import 해줘야합니다.

**useState는**  
기본적으로 리액트 라이브러리에서 제공하는 함수인데  
컴포넌트 함수가 다시 호출되는 곳에서 변경된 값을 반영하기 위해  
state로 값을 정의할 수 있도록 도와주는 함수입니다.

useState를 리액트 훅이라고 부르며 여러가지가 있습니다.  
훅들의 이름은 use로 시작하기 때문에 쉽게 알 수 있습니다.

사용시 중요한 점이라면 리액트 컴포넌트 함수 안에 호출 되어야 합니다.  
컴포넌트 함수 밖에도, 컴포넌트 함수 안에 중첩된 함수 안에도 호출 하면 안됩니다.

![](/images/react-35/6.png)

-   useState는 props.title이라는 초기값을 설정할 수 있습니다.
-   useState 함수를 호출해서 새로운 값을 할당합니다.  
    이것이 state 변수가 작동하는 방식입니다.
-   배열 구조분해라는 기능을 이용하여 독립된 두 요소인 변수나 상수를 저장합니다.  
    그것이 title과 setTitle입니다,
-   첫번째 값인 title은 관리되고 있는 값을 말하며 현재는 props.title이 저장되어 있습니다.  
    두번째 값인 setTitle은 업데이트 되는 함수입니다.
-   useState라는 훅은 항상 두 개의 요소가 있는 배열을 반환합니다.

리액트를 사용하면서 변화하는 데이터를 가지고 사용자 인터페이스에 반영되어야 한다면  
위에 state를 꼭 사용해야합니다.

state를 이용해야만 리액트에서 state가 등록된 컴포넌트를 재평가할 것이고  
그래야 화면이 변화합니다.

![](/images/react-35/7.png)

사용은 위처럼 하면 됩니다.

setTitle을 함수처럼 사용하여 값을 변경해줍니다.

* * *

![](/images/react-35/8.png)

setTitle을 하고 난 뒤 console 창에 title을 띄워 보면... 당연히 updated가 되어야 하는 데  
이상하게 전 값이 나옵니다.

이 이유는 setTitle은 사실상 바로 값을 바꾸는 것이 아닌 state의 업데이트를 예약합니다.
