### **\- React = component**

꼭 생각해야 할 것 , 리액트는 사용자 인터페이스를 구축하는 **자바스크립트** 라이브러리라는 것.

html, Css, Javascript 도 사용자 인터페이스를 구축하고 충분히 웹사이트를 만들 수 있습니다.  
하지만 리액트를 사용하면 훨씬 더 수월 할 것이라는 것.

리액트에서 컴포넌트는 매우 중요하며 컴포넌트가 다라고 해도 될 정도입니다.

컴포넌트란 쉽게 말해서 웹사이트에서 보여지는 모든 것이 컴포넌트입니다.  
차트, 버튼, 입력창, 출력창 모든 부분이 컴포넌트이며  
이런 컴포넌트 들을 잘 조립해서 이쁜 웹사이트를 만들면 되는 것입니다.

리액트가 이런 컴포넌트의 개념을 도입한 이유는  
재사용이 가능하다는 것과 불필요한 코드를 사용하지 않기 위해서입니다.

버튼, 입력창 같은 경우 하나만 만들어놓는다면 계속 사용할 수 있습니다.  
사용하고 싶을 때 import 하고 넣어주기만 하면 매우 간단하게 코드를 불리지 않고 사용 가능합니다.

방금 말한 것과 같은 개념이지만 재사용 가능한 블록들은 반복을 피할 수 있게 합니다.

### **\- JSX**

분명 React는 자바스크립트라고 했습니다.  
그런데 우리는 너무 당연하게 <div> 태그를 사용하며 html을 쓰는 것처럼 사용합니다.

![](/images/react-33/1.png)

JSX는 자바스크립트를 확장한 문법으로 자바스크립트 XML을 의미합니다.

이런 코드를 사용하여 보이는 화면은 컴퓨터에서 코드를 변환 시켜주면서 보여지는 화면입니다.

우리가 코드를 작성하고 쓰는 npm start 프로세스는 자바스크립트 코드를 브라우저 친화적인 코드로 변환시킵니다.

JSX 가 없었다면 <div> </div> 이런 간단한 코드도  
return React.createElement('div', {}, ,);  
이런 식으로 사용했어야 합니다.

### **\- React 소소한 규칙?**

1.  리액트 프로그램 이름을 만들 때는 대문자로 시작하는 한 단어이고  
    중간에 시작하는 서브 단어 또한 대문자로 시작해야 합니다.
2.  이름은 파일을 대표하며 파일 이름만으로 어떤 코드인지 알 수 있도록 적는 것이 좋습니다.
3.  소문자로 시작하는 요소는 내장된 html 요소.  
    대문자로 시작하면 우리나 다른 개발자들에 의해 정의된 요소.
4.  import 할때 .js 는 생략해줍니다.
5.  반환 (return) 할 때는 한 덩어리, <div> </div>로 묶든 <></>로 묶든 아무튼 한 덩어리로 만들어 줘야 합니다
