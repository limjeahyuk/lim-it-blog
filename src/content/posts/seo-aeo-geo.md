## SEO AEO GEO

> AI의 발전으로 인해서 요즘은 구글 검색보다 AI 에게 물어보는 것이 우선시 되곤 합니다.  
> 이런 상황에서 손놓고 있을 순 없습니다. 그렇다면 내 게시물이 AI에게 선택 받는 방법을 알아야할 듯합니다.

### SEO

**검색 엔진 최적화 ( Search Engine Optimization )**



구글, 네이버 등 전통적인 검색 엔진의 결과 페이지에서 웹 사이트를 상단에 노출 시키기 위한 가장 전통적인 전략.



- **목표**  
특정 키워드 검색 시 상위에 랭크되어 웹사이트 트래픽과 클릭률을 극대화하는 것.



- **주요 전략**
  - 사용자가 많이 검색하는 타겟 키워드를 발굴하여 제목과 본문에 적절히 배치.
  - 신뢰도를 높이기 위한 백링크(외부 웹사이트에서 내 사이트로 걸어주는 링크) 구축.
  - 페이지 로딩 속도 개선, 모바일 최적화, 메타 태그 작성 등 기술적 환경 개선.

### **AEO**

**답변 엔진 최적화 (Answer Engine Optimization)**



구글의 추천 스니펫이나 시리, 구글 어시스턴트 등 음성 비서가 사용자의 질문에 즉각적인 답변을 제공하도록 콘텐츠를 구성하는 전략입니다.



- **목표**  
누가, 언제, 어디서, 무엇을 등 구체적인 질문에 대한 가장 정확한 답변으로 채택되는 것.



- **주요 전략**
  - 콘텐츠를 FAQ 형태로 구성하여 질문-답변 구조를 명확히 함.
  - 핵심 결론을 문단의 가장 앞에 두는 두괄식 구조와 간결한 문장 사용.
  - 검색 엔진이 데이터의 의미를 쉽게 이해하도록 돕는 스키마 마크업 적용.

### **GEO** 

**생성형 엔진 최적화 (Generative Engine Optimization)**



챗GPT 검색 같은 LLM 기반의 생성형 AI 검색 엔진이 답변을 생성할 때, 내 콘텐츠를 신뢰할 수 있는 출처로 인용하도록 만드는 최신 전략입니다.



- **목표**  
AI가 여러 정보를 합성하여 작성하는 종합적인 답변 내에 인용 링크 및 각주로 언급되는 것.



- **주요 전략**
  - 단순 키워드 반복이 아닌, 해당 주제에 대한 깊이 있는 분석과 독창적인 인사이트 제공.
  - AI가 사실 관계를 쉽게 검증하고 인용할 수 있도록 명확한 통계 자료, 1차 원본 데이터, 전문가의 인용구 포함.
  - 경험, 전문성, 권위, 신뢰성을 강조하여 AI에게 정확하고 안전한 정보 출처로 인식시키기.

| ------------- | ----------------------------- | ------------------------------- | -------------------------------------------- |

| **핵심 최적화 요소** | 키워드 밀도, 백링크, 기술적 최적화          | 질문-답변 구조(FAQ), 간결성, 스키마 마크업     | 문맥의 깊이, 독창적 데이터, 전문성(E-E-A-T)                |

### 개발 단에서 SEO AEO GEO를 향상 시키는 방법



**렌더링 및 DOM 최적화 (SEO &amp; GEO 공통)**

- **SSR(서버 사이드 렌더링) 및 SSG(정적 사이트 생성)**  
Next.js, Nuxt.js 등을 활용해 자바스크립트 실행 없이도 크롤러와 AI 봇이 완전한 HTML 콘텐츠를 즉시 수집할 수 있도록 아키텍처를 구성합니다.   
순수 CSR(클라이언트 사이드 렌더링)로 구성된 SPA는 봇의 정보 수집 누락을 유발합니다.
- **시맨틱 태그 엄격 적용 및 DOM 경량화**  
불필요한 `<div>` 중첩을 피하고 `<article>`, `<main>`, `<aside>`, `<nav>` 등 HTML5 시맨틱 태그를 사용하여  
AI 파서가 내비게이션, 광고, 본문을 정확히 분리해 핵심 정보만 파싱하도록 만듭니다.



**구조화된 데이터 주입 자동화 (AEO)**

- **동적 JSON-LD 스크립트 렌더링**  
데이터베이스에 저장된 게시글 본문, FAQ 리스트, 작성자 이력을 매핑하여 [Schema.org](http://Schema.org) 규격에 맞는 JSON-LD 코드를 페이지 `<head>` 영역에 자동 삽입하는 백엔드/프론트엔드 유틸리티를 개발합니다.
- **동적 메타 태그 라우팅**  
각 페이지의 URL 파라미터나 상태에 따라 Open Graph, Twitter Cards, Canonical URL 메타 태그를 서버 단에서 주입하여 중복 페이지 문제를 방지합니다.



**Core Web Vitals 개선 (SEO)**

- **미디어 에셋 파이프라인 구축**  
이미지 업로드 시 서버(또는 람다 함수)에서 자동으로 WebP/AVIF 포맷 변환 및 리사이징을 수행하도록 구성하고,   
프론트엔드에서는 `loading="lazy"` 속성과 `srcset`을 적용합니다.
- **코드 스플리팅**  
번들러(Webpack, Vite 등) 설정에서 청크를 분리하여 렌더링 차단 리소스를 줄이고, 초기 로딩 시간과 반응성을 개선합니다.



**AI 봇 라우팅 및 접근 제어 (GEO)**

- **AI 크롤러 전용 User-Agent 대응**  
미들웨어 단에서 `ChatGPT`, `PerplexityBot`, `Google-Extended` 등의 생성형 AI 크롤러를 식별하여 렌더링을 방해하는 무거운 팝업, 캡차, 무한 스크롤을 우회시키는 로직을 추가합니다.
- **클린 데이터 엔드포인트**  
AI 엔진이 데이터를 쉽게 학습하고 인용할 수 있도록, 웹 UI 요소가 제거된 순수 Markdown이나 JSON 형태의 본문 데이터를 반환하는 크롤러 전용 엔드포인트를 구축할 수도 있습니다.
